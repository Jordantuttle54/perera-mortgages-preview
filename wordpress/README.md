# Perera Mortgages WordPress build — first milestone

This directory contains a custom, full-site-editing WordPress block theme based on the approved V4 homepage in `Jordantuttle54/perera-mortgages-preview` (source blob `9b6f5098c57f7984219475105971a0f3463ce171`). It is intended to be installed under `wp-content/themes/perera-mortgages` on a staging WordPress site.

## Included

- Approved homepage layout, wording, palette, typography, mobile behaviour and reduced-motion support.
- Reusable header and footer template parts.
- Reusable service-grid and three-step process patterns.
- Default page template plus mortgage-service and contact page templates.
- WordPress design tokens in `theme.json` and responsive styles in `style.css`.
- Existing embedded foreign-national couple image extracted from the approved prototype.
- A self-contained `preview.html` with inline styles and its local image embedded, so it displays correctly when opened directly from a phone download. The two Pexels photographs still require an internet connection.
- A WordPress-ready Foreign National Mortgages page draft and a clearly named, self-contained `Perera-Foreign-National-Mortgages-Visual-Preview.html` for review.

## Before production

- Confirm rights and approval for the hero and Sri Lanka photography. The current theme retains the preview's Pexels URLs pending that check.
- Replace the generic FCA Register homepage URL with the verified firm record URL.
- Confirm compliance approval of the regulatory footer and each page's financial-promotion copy.
- Create and populate the site pages so the navigation and service-card links resolve.
- Add cookie/privacy controls only after confirming the host, analytics, form and other data-processing services.
- Confirm PHP/WordPress versions and test this theme on the actual chosen WordPress hosting before launch.

The theme does not add a contact form or third-party plugins. The contact page uses the supplied phone and email links until the enquiry handling route is agreed.
